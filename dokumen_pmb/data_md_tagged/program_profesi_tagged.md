# Program Profesi
<!-- intents: tanya_profesi, tanya_prodi_fakultas -->
<!-- topik: Program Profesi UIN Syarif Hidayatullah Jakarta -->
<!-- alias_topik: program profesi, profesi UIN Jakarta, PPG, Profesi Apoteker, Profesi Ners, Profesi Dokter -->
Program profesi oleh UIN Syarif Hidayatullah terdiri dari Program Studi Profesi Guru, Program Profesi Apoteker, Program Profesi Ners dan Program Profesi Dokter. Program profesi dari masing-masing fakultas telah menghadirkan inovasi terbaik untuk mewujudkan sistem pembelajaran yang dapat menunjang calon mahasiswa untuk mendapatkan hasil terbaik dari program studi profesi ini.
