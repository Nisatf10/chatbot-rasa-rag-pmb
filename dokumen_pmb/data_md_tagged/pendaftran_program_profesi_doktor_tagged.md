## Prosedur Login Formulir Calon Mahasiswa
<!-- intents: tanya_profesi, tanya_prosedur_pendaftaran -->
<!-- topik: Prosedur Login Formulir Calon Mahasiswa Program Profesi Dokter -->
<!-- alias_topik: login formulir profesi dokter, ID PIN profesi dokter, kode bayar profesi dokter -->
1. Calon mahasiswa sudah melakukan proses Generate Kode Bayar.
2. Calon mahasiswa sudah mendapatkan ID dan PIN.
3. Calon mahasiswa sudah melakukan pembayaran di bank Mitra UIN Syarif Hidayatullah Jakarta, menggunakan Kode Bayar (99xxxxxxxxxxxx).

## Prosedur Login Pendaftaran Ulang Calon Mahasiswa
<!-- intents: tanya_profesi, daftar_ulang -->
<!-- topik: Prosedur Login Pendaftaran Ulang Program Profesi Dokter -->
<!-- alias_topik: login daftar ulang profesi dokter, pendaftaran ulang profesi dokter -->
1. Calon mahasiswa sudah dinyatakan Lulus (sesuai Jenjang yang didaftarkan) pada Universitas Islam Negeri Syarif Hidayatullah Jakarta.
2. Calon mahasiswa sudah mendapatkan kelompok UKT (untuk Program Sarjana dan Program Profesi).
3. Calon mahasiswa sudah melakukan pembayaran di bank Mitra UIN Syarif Hidayatullah Jakarta, menggunakan Nomor Peserta.
